医械法规文档术语库

中英对照，98 条高频术语。这份表的价值不在「翻译对不对」，而在标出了容易译反的 13 个坑—— 它们不是词典释义分歧，而是审评与翻译实务里反复出现的混淆点。

98 条术语 7 个分组 13 处高频误译 来源：MDR / ISO 13485 / ISO 14971 / ISO 15223-1 语境
共 98 条

A器械与结构

骨科与手术器械语境。这一组最容易出错的是 trial、broach、rasp 这几个。

English中文说明 / 易错点
implant植入物区分 implant（植入物，名词）与 implantable（植入式，形容词）
prosthesis假体复数 prostheses；关节置换语境固定用「假体」
trial / trial component试模 / 试模件易错骨科术中试复位用件，不译「试验」「试用」
broach髓腔锉易错机械领域译「拉刀」，骨科语境必须是「髓腔锉」
impactor打击器 / 打入器胫骨冲击锉手柄类器械常与 broach 连用
reamer铰刀 / 扩髓钻骨科扩髓用「扩髓钻」；髋臼用「髋臼锉」
rasp骨锉与 broach 区分：rasp 是表面修整，broach 是成形
forceps钳arthroscopic forceps = 关节镜钳；单复数同形
stem柄femoral stem = 股骨柄，不译「杆」
acetabular cup髋臼杯外杯为 shell，内衬为 liner
liner / insert内衬 / 衬垫同一语境下不要混用；liner 多用于髋，insert 多用于膝
femoral head股骨头 / 球头器械语境用「球头」，解剖语境用「股骨头」
modular模块化modular stem = 模块化柄
instrumentation器械 / 手术器械不可译为「仪器」；器械包为 instrument set / tray
single-use一次性使用对应 single-use device；勿写「一次性用品」
reusable可重复使用MDR 中 class I reusable surgical instrument 有专门过渡规则

B材料与表面处理

喷砂件、钝化件的清洁验证与生物相容性文件里高频出现。

English中文说明 / 易错点
stainless steel不锈钢630 不锈钢即 17-4PH 沉淀硬化型，写法保持「630」不换算
passivation钝化易错不是「活化」「钝化处理剂」；是去除游离铁形成钝化膜
sandblasting / grit blasting喷砂写明磨料与粒径；与 shot blasting（钢丸）区分
bead blasting喷玻璃珠（珠击清理）磨料为玻璃珠/陶瓷珠；不要译作「喷丸」——「喷丸」对应 shot blasting（钢丸）
electropolishing电解抛光常与 passivation 前后使用，注意工序顺序表述
anodizing阳极氧化钛件常用；不可写「阳极处理」
Ti-6Al-4V钛合金（TC4）材料牌号保留原写法，中文补注 TC4 即可
nitinol / nickel-titanium镍钛合金首次出现写「镍钛合金（Nitinol）」，后文统一用「镍钛」
UHMWPE超高分子量聚乙烯保留缩写 UHMWPE，首次出现给全称
PEEK聚醚醚酮保留缩写
surface roughness (Ra)表面粗糙度标注单位 μm，不要省略
corrosion resistance耐腐蚀性不是「抗腐蚀能力」
machined机加工与 forged（锻造）、cast（铸造）并列出现时保持句式一致

C灭菌与洁净

这一组是翻译事故的高发区，sterile 和 sterilization 最常被混成「消毒」。

English中文说明 / 易错点
sterilization灭菌易错灭菌 ≠ 消毒。disinfection 才是「消毒」，两者不可互换
sterile无菌sterile device = 无菌器械；勿写「消毒过的」
sterility assurance level (SAL)无菌保证水平写作 10⁻⁶ 形式，保留上标
moist heat sterilization湿热灭菌134 ℃ 3 min / 121 ℃ 15 min 是常见参数组合
ethylene oxide (EO)环氧乙烷残留量表述用 EO residue，不是「环氧乙烷残渣」
autoclave压力蒸汽灭菌器口语「高压锅」不可入正式文件
bioburden生物负载易错不是「生物负担」「生物负荷」
endotoxin内毒素限值常以 EU/mL 或 EU/device 表示
pyrogen致热原与 endotoxin 不是同义词，勿合并
limulus amebocyte lysate (LAL)鲎试剂保留 LAL 缩写；鲎字不要写错
cleaning validation清洁验证注意与 cleaning verification 区别，见 F 组验证/确认条
residue残留物cleaning residue = 清洁残留物
reprocessing再处理单次使用器械再处理属高风险议题，措辞须谨慎
aseptic无菌（操作）aseptic processing = 无菌工艺
sterile barrier system无菌屏障系统缩写 SBS；保留缩写便于与公告机构沟通

D包装与标识

IFU 与标签是审评最常挑格式问题的地方，术语必须逐字稳定。

English中文说明 / 易错点
instructions for use (IFU)使用说明书易错不是「使用指导」「说明书」；中文法规文书中固定用「使用说明书」
labelling标签标识label 是实物标签，labelling 是含标签与随附信息的整体
unique device identification (UDI)唯一器械标识不译「设备唯一识别码」
Basic UDI-DI基本 UDI-DI保留原文不译，EUDAMED 字段名需与原文一致
shelf life货架寿命 / 有效期同一文件内统一一种说法，不要混用
expiry date失效日期格式按目标市场要求（YYYY-MM-DD 或 YYYY-MM）
summary of safety and clinical performance (SSCP)安全与临床性能摘要植入类与 III 类适用
symbols符号引用 ISO 15223-1，符号不得自行改绘
single sterile barrier单一无菌屏障对应 single sterile barrier system（SSBS）
intended purpose预期用途易错不是「预期目的」。MDR 第 2(12) 条定义的是 intended purpose（预期用途）；intended use 属 FDA/IMDRF 用语，翻译欧盟文件时不要互换

E法规与注册

MDR / FDA / NMPA 三个体系混用时，同一个中文词可能对应不同英文，必须按体系固定。

English中文说明 / 易错点
conformity assessment符合性评定ISO/CASCO 体系内也译「合格评定」，同一文件选一种并保持一致
notified body公告机构易错不译「认证机构」「发证机构」；可简写 NB，但首次出现须写全「公告机构（notified body, NB）」
technical documentation技术文档统一用「技术文档」；「技术文件」在 NMPA 语境可对译，但同一份文件内不得混用
general safety and performance requirements (GSPR)通用安全与性能要求保留 GSPR 缩写
declaration of conformity符合性声明不是「合格证」
CE markingCE 标识不是「CE 认证」；CE 标识由制造商自我声明并承担全部责任，但 MDR 下除部分 I 类器械外均须公告机构参与符合性评定——措辞影响法律表述
equivalence等同性equivalence route = 等同性路径，临床评价常用
clinical evaluation临床评价与 clinical investigation（临床试验）区分
clinical evaluation report (CER)临床评价报告保留 CER 缩写
post-market clinical follow-up (PMCF)上市后临床跟踪MDR 语境统一用「上市后临床跟踪」；「上市后临床随访」在部分文献中通用，但同一份文件内不得混用
post-market surveillance (PMS)上市后监督与 PMCF 并列但不相同，勿混
periodic safety update report (PSUR)定期安全性更新报告MDR 第 86(1) 条第二段：IIa 在必要时且至少每 2 年更新，IIb 与 III 至少每年更新（以 EUR-Lex 第 86 条原文为准）
vigilance警戒不译「 vigilance 监测」这类中英混写
field safety corrective action (FSCA)现场安全纠正措施常与 FSN（现场安全通知）配套
serious incident严重事件与 serious adverse event 区分，后者多用于临床试验
legal manufacturer法定制造商不译「合法制造商」
authorised representative授权代表欧盟境内，缩写 EC REP
importer / distributor进口商 / 经销商MDR 下两者义务不同，不可合并为「代理商」
significant change重大变更判定标准影响是否需重新评定，措辞须严格
transitional provision过渡条款MDR Article 120 语境

F风险与质量

hazard / harm / residual risk 这一组是 ISO 14971 翻译的重灾区，错一个整段逻辑就反了。

English中文说明 / 易错点
hazard危害易错hazard = 危害（潜在来源），不是「危险」
hazardous situation危险情况人暴露于危害时所处的状态
harm伤害易错harm = 伤害（已造成），不是「危害」
severity严重度不是「严重性」「严酷度」
probability of occurrence发生概率与 probability of harm 区分
residual risk剩余风险易错不是「残留风险」；residual 在此为「剩余」
risk control风险控制风险控制措施 = risk control measure
nonconformity不合格不译「不符合项」（后者多指审核发现）
corrective and preventive action (CAPA)纠正和预防措施保留 CAPA；corrective 与 preventive 不可只译一半
design control设计控制FDA 语境高频
design history file (DHF)设计历史文档与 DMR、DHR 三者常被混
device master record (DMR)器械主记录含成品规格与工艺
device history record (DHR)器械历史记录某一批的生产记录
verification验证易错对「规定要求」的符合性——做对了吗
validation确认易错对「预期用途」的符合性——做的是对的东西吗。中文直觉常把两者译反

G测试与验证

生物相容性与力学性能报告里的固定搭配。

English中文说明 / 易错点
biocompatibility生物相容性不译「生物兼容性」
cytotoxicity细胞毒性ISO 10993-5 语境
sensitization致敏与 irritation（刺激）并列，勿合并
mechanical fatigue机械疲劳写明循环次数与载荷水平
wear磨损wear rate = 磨损率；wear debris = 磨损颗粒
torque扭矩单位 N·m，不要写成 Nm 混排
pull-out strength拔出力骨科螺钉/锚钉常用
accelerated aging加速老化对应 shelf-life study 的常用方法
shelf-life study货架寿命研究与 accelerated aging 配套表述
没有匹配的术语。试试只搜英文单词或中文两个字。

使用规范（比术语本身更重要）

术语库的价值不在条目多少，在「谁能改、怎么改、改了怎么溯源」。

四条硬规则

  1. 一个项目一份锁定版。项目启动时把当前版本号写进项目书，项目期间不跟随术语库升级，避免中途漂移。
  2. 客户指定优先。客户已有内部术语表的，以客户为准，冲突项单列一张 conflict 表并在交付时说明。
  3. 改一条必须写理由。任何修改记录三样：原译、新译、为什么。没有理由的修改一律驳回。
  4. 法规原文不改写。GSPR 条款、法规名称、机构名称一律照原文，只做语言转换，不做意译。「不超过」不能写成「大约」。
