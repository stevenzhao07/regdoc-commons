MDR 一致性核对

把两边的器械清单贴进来，按你勾选的列自动比对，输出「只在 A 有」「只在 B 有」「字段值不一致」三类差异，另加重复主键、风险等级写法、Basic UDI-DI 分布三项数据质量提示。 纯本地运行，数据不上传。

1粘贴两边数据

直接从 Excel 复制粘贴即可（支持 Tab 或逗号分隔，带引号的字段也能处理）。第一行必须是表头。

2设定主键与比对列

主键用来匹配两边的同一条器械。通常用 UDI-DI；没有 UDI 的话用「型号」。

粘贴数据后，这里会列出两边同名的列，可勾选要比对哪些。

3核对规则

这几条直接决定误报率。默认值适合大多数情况。

这个工具多做的那一层

四条按 MDR 语境写进工具的规则（通用 diff 工具没有）

  • 风险等级写法校验（只查写法，不判分类）。MDR 分类写作 I / Is / Im / Ir / IIa / IIb / III。出现 II、2 类、2 等 MDD / FDA 写法会被标出。是否应为 Is / Im / Ir 取决于灭菌状态、是否有测量功能、是否可重复使用，不由器械名称推断——若名称像可重复使用手术器械而写法只有 I，工具只提示「请人工确认」，不作判定。
  • Basic UDI-DI 与 UDI-DI 的层级关系（信息性，不计入差异）。同一个 Basic UDI-DI 下可能对应多条 UDI-DI（不同包装层级或型号），也可能只有一条——单条不视为异常。工具只列出每个 Basic UDI-DI 的 UDI-DI 条数，请按该产品的实际包装层级人工确认。
  • 预期用途不逐字比对。不同来源的措辞必然不同，逐字比会全是误报。工具只做「缺失关键词」提示，关键词由你在比对列里手动控制。
  • 重复主键检测。一边出现两条相同 UDI-DI 是脏数据，会让后面的比对结果整体失真，所以单独列出来。

核对前必查（8 条清单）

  • 两边的 UDI-DI 是否都已去掉首尾空格、且格式一致（GS1 是 14 位数字）
  • B 表是否为完整导出，而不是筛选后的部分视图
  • 风险等级列是否混用了 MDD 旧分类与 MDR 新分类
  • 型号列是否存在「同一型号多种写法」（如 X-100 / X100 / X 100）
  • 预期用途是否被 Excel 截断（单元格字符上限）
  • 是否有器械在 B 表存在但已停产，不应算作缺项
  • Basic UDI-DI 是否同一型号组共用一个
  • 证书编号是否与公告机构四位数代码对应

本工具不替代法规原文。所有判定为「提示」而非「结论」，最终判断须由有资质的人员签核。

数据全程在本地浏览器内处理，不上传任何服务器。页面刷新即清空，请及时导出结果。
